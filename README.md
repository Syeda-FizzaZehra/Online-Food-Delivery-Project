# Online Food Delivery Business Intelligence & Performance Analysis Using SQL
Generate actionable business insights from an online food delivery platform using SQL.

## About the Project
This project analyzes an online food delivery business database using SQL to uncover insights into revenue, customer behavior, restaurant performance, and delivery efficiency. 
It demonstrates business intelligence techniques and data-driven decision-making using SQL queries.


**Key Findings / Insights**  
- Top revenue-generating restaurants and cities  
- Repeat customer trends  
- Delivery agent performance metrics
